# ANG3L FORUM
A fast & lightweight PHP forum site, using SQLITE for the database.

try it out: ```php -S localhost:8000 -t public```

<br>
Add these lines to the bottom of your php.ini config:
<br>
<p >extension=sqlite3</p>
<p style='color: blue;'>extension=pdo_sqlite</p>
